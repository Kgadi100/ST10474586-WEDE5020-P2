KGADI'S ARTISAN BAKERY WEBSITE.

Kgadi's artisan bakery is a website designed to showcase a range of freshly baked products and provide customers with information about the bakery and its services. The website contains multiple interconnected pages, including home, about, products, and enquiry pages. Thew website was developed using html, CSS, and JavaScript and was designed to provide a clear and user-friendly experience on desktop, tablet and mobile devices.
